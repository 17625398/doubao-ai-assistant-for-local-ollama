# 提示词使用指南

## 1. 什么是提示词？

提示词（Prompt）是你给AI模型的指令，告诉它你想要什么以及如何回答。一个好的提示词可以帮助AI模型生成更准确、更有用的回答，提高工作效率和质量。

## 2. 提示词设计原则

### 2.1 明确具体
- **清楚地表达你的需求**：使用明确、具体的语言，避免模糊和歧义
- **提供足够的上下文信息**：添加相关背景信息，帮助AI理解你的需求
- **指明你期望的输出格式**：明确要求AI按照特定格式输出结果

### 2.2 结构化
- **使用层次结构组织你的提示词**：使用标题、列表等结构，使提示词清晰易读
- **按逻辑顺序排列信息**：先提供背景信息，再提出具体要求
- **使用编号或项目符号**：使内容清晰易读，便于AI理解

### 2.3 提供示例
- **当你需要特定格式的输出时，提供示例**：示例可以帮助AI更好地理解你的需求
- **示例应该与你的实际需求相关**：使用真实的、与任务相关的示例
- **提供多个示例**：如果可能，提供多个示例，帮助AI理解不同情况下的处理方式

### 2.4 设置约束条件
- **明确指出你不想要什么**：例如，"不要使用专业术语"、"避免过于复杂的解释"等
- **设定回答的长度限制**：例如，"回答不超过200字"、"使用简洁的语言"等
- **指明不应该使用的语言或风格**：例如，"不要使用幽默的语言"、"避免使用俚语"等

### 2.5 调整复杂度
- **根据任务的复杂度选择合适的提示词长度**：简单任务使用简洁的提示词，复杂任务提供更详细的上下文和指导
- **使用适当的专业术语**：根据任务的专业程度，使用适当的专业术语
- **平衡详细程度和简洁性**：提供足够的信息，同时保持提示词简洁明了

## 4. 常见问题与解决方案

### 4.1 问题：AI生成的回答不够详细
**解决方案**：在提示词中明确要求详细回答，例如："请提供详细的回答，包括具体的步骤和例子。"

### 4.2 问题：AI生成的回答偏离主题
**解决方案**：在提示词中明确主题范围，例如："请仅围绕主题X回答，不要涉及其他无关内容。"

### 4.3 问题：AI生成的回答格式不符合要求
**解决方案**：在提示词中明确格式要求，例如："请按以下格式回答：1. 问题分析；2. 解决方案；3. 实施步骤。"

### 4.4 问题：AI生成的回答过于技术化
**解决方案**：在提示词中要求使用通俗易懂的语言，例如："请使用通俗易懂的语言回答，避免使用专业术语。"

### 4.5 问题：AI生成的回答缺乏创新性
**解决方案**：在提示词中鼓励创新，例如："请提供创新的解决方案，不要局限于传统方法。"
