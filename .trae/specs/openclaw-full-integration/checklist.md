# OpenClaw 全面集成融合 - 验证清单

## 运行时基线
- [ ] 本项目能够检测 `openclaw` CLI 是否已安装
- [ ] 本项目能够识别 Node.js 版本是否满足 OpenClaw 运行要求
- [ ] Windows 环境能够显示 WSL2 优先接入建议
- [ ] `@doubao/core`、`@doubao/web`、浏览器扩展和本地服务层职责清晰

## Gateway 接入
- [ ] 能够检测 OpenClaw Gateway 是否运行
- [ ] 能够启动、停止、重启 Gateway
- [ ] 能够读取 Gateway 基本状态、端口、认证模式和版本信息
- [ ] Gateway 不可用时能够提供明确修复建议
- [ ] `doctor` 或同类诊断结果能够被展示和理解

## 首次引导
- [ ] 首次接入流程包含 CLI 安装、环境校验、`onboard` 和模型配置指引
- [ ] 平台差异说明清晰，包含 Windows、macOS、Linux 的关键限制
- [ ] 常见失败场景有可复制的命令或可执行的恢复步骤

## 配置与安全
- [ ] 能够读取并编辑 OpenClaw 配置
- [ ] 模型、workspace、channels、browser、sandbox、auth、tailscale、voice、nodes 等关键配置项可见
- [ ] 高风险配置存在风险提示或确认步骤
- [ ] 默认遵循 DM pairing、allowlist 和最小权限原则
- [ ] 敏感令牌和凭据不会在普通日志与界面中明文泄露

## 多渠道管理
- [ ] 能够展示已支持或已安装的 OpenClaw 渠道
- [ ] 渠道可以启用、禁用和查看最近连接状态
- [ ] 渠道登录流程可达，支持二维码、Token 或凭据提示
- [ ] allowlist、DM policy、群组策略可查看或编辑
- [ ] 渠道配置错误时能给出明确诊断

## 消息与 Agent
- [ ] 入站消息能映射到本项目统一消息模型
- [ ] 出站消息能通过正确渠道发送
- [ ] 会话能够按渠道、联系人、群组或线程隔离
- [ ] 支持为不同来源绑定不同 Agent
- [ ] 不同 Agent 的上下文不会串扰
- [ ] 群聊、reply-back 或跨会话场景有明确行为定义

## 知识库与记忆
- [ ] 本项目知识库结果能够进入 OpenClaw 会话流程
- [ ] 文档上传、检索和引用链路清晰
- [ ] 渠道消息、会话摘要和工具结果能够写入本项目记忆系统
- [ ] 能按 Agent、会话、渠道维度回溯记忆内容
- [ ] 用户能够理解回答中的知识引用和记忆来源

## Skills 与 Workspace
- [ ] 能够展示 OpenClaw workspace 和技能目录
- [ ] 能够识别 bundled、managed、workspace 三类技能来源
- [ ] 技能支持查看说明、启停、安装和执行
- [ ] 工具参数录入和执行结果展示完整
- [ ] 技能失败时能提供可理解的错误信息
- [ ] 技能安装前有权限或风险提示

## Browser 与 Oh My Browser
- [ ] 能够检测 OpenClaw Browser 或相关浏览器能力状态
- [ ] 能够发起页面快照、基本控制或相关浏览器动作
- [ ] 浏览器扩展能力与 OpenClaw Browser 有清晰分工和联动
- [ ] `oh-my-browser` 插件安装路径明确
- [ ] 授权缺失时能提示执行 `omb login`
- [ ] CLI 缺失时能提示安装 `omb` 和相关插件
- [ ] 浏览器桥接失败时能提示检查 Chrome、扩展连接或重启 Gateway

## 事件与日志
- [ ] Gateway 关键事件能进入统一事件总线
- [ ] 渠道状态变化、技能执行和浏览器操作能被记录
- [ ] 日志支持查看最近事件、分类筛选和诊断摘要
- [ ] 错误日志具备恢复建议
- [ ] 日志导出或复制诊断信息能力可用

## 远程模式
- [ ] 支持配置远程 Gateway 连接
- [ ] Tailscale/SSH 等模式有清晰说明
- [ ] 远程连接成功后能够展示认证状态与连接限制
- [ ] 高风险远程能力不会默认开放
- [ ] 远程模式下的降级行为清晰可见

## 高级能力
- [ ] Canvas 能力至少具备状态展示或基础入口
- [ ] Nodes 能力至少具备节点状态和权限可见性
- [ ] Voice 能力至少具备可用状态展示和平台限制说明
- [ ] WebChat/Control UI 能够以内嵌或跳转方式接入
- [ ] 不支持的平台有明确降级提示，不会误导用户

## 整体体验
- [ ] OpenClaw 相关入口已整合进本项目聊天页、工具面板、设置页、技能页或侧边栏
- [ ] 状态文案、错误提示和恢复动作保持一致
- [ ] 能力缺失、环境未就绪或插件异常时界面能够优雅降级
- [ ] 整体交互连贯，不会让用户在多个入口之间迷失
