# All-Model-Chat 深度集成规格文档

## 为什么

参考 All-Model-Chat 项目的优秀功能，深度优化豆包AI助手的网页内容提取功能，实现更智能的URL内容抓取、深度搜索集成和Canvas交互渲染，提升用户体验。

## 变更内容

- **新增** URL自动检测与内容抓取功能
- **新增** 深度搜索面板和API集成
- **新增** Canvas代码预览功能（HTML/CSS/JS、ECharts、Mermaid）
- **新增** ZIP文件解析和代码库结构展示
- **优化** 现有的网页内容提取算法
- **优化** 文件上传和处理流程

## 影响范围

- 受影响的组件：ChatInput、MessageItem、CodeBlock、WebContentExtractorPanel
- 受影响的API：/api/read（增强）、新增 /api/search
- 新增组件：CanvasPreviewPanel、SearchPanel、ZipFileBrowser

## 新增需求

### 需求1: URL自动检测与内容抓取

系统应自动检测用户输入中的URL，并提供抓取选项。

#### 场景1.1: 检测到单个URL
- **当** 用户在输入框粘贴或输入包含URL的文本
- **然后** 系统高亮显示检测到的URL
- **并且** 显示"抓取内容"按钮
- **当** 用户点击按钮
- **然后** 异步抓取URL内容
- **并且** 将内容添加到消息上下文

#### 场景1.2: 抓取失败处理
- **当** URL抓取失败（网络错误、403禁止等）
- **然后** 显示友好的错误提示
- **并且** 提供"重试"和"跳过"选项

#### 场景1.3: Token限制处理
- **当** 抓取的内容超过Token限制
- **然后** 智能截断内容（保留标题、摘要、前N段落）
- **并且** 显示"内容已截断"提示和原始长度/压缩率

### 需求2: 深度搜索集成

系统应支持深度搜索功能，自动规划搜索任务并整合结果。

#### 场景2.1: 触发深度搜索
- **当** 用户点击"深度搜索"按钮或输入特定指令
- **然后** 分析查询意图
- **并且** 规划多步骤搜索任务
- **当** 搜索完成
- **然后** 聚合结果并生成带引用的回答

#### 场景2.2: 搜索结果展示
- **当** 搜索结果返回
- **然后** 在面板中显示搜索结果列表
- **并且** 每个结果显示标题、摘要、来源链接
- **当** 用户点击结果
- **然后** 在新标签页打开原始页面

### 需求3: Canvas代码预览

系统应支持AI生成代码的交互式预览。

#### 场景3.1: HTML/CSS/JS预览
- **当** AI返回包含HTML/CSS/JS的代码块
- **然后** CodeBlock组件显示"预览"按钮
- **当** 用户点击预览
- **然后** 在iframe中渲染代码
- **并且** 提供全屏查看选项

#### 场景3.2: ECharts图表渲染
- **当** AI返回ECharts配置代码
- **然后** 自动识别并显示图表预览
- **并且** 支持图表交互（悬停、缩放等）

#### 场景3.3: Mermaid流程图
- **当** AI返回Mermaid语法代码
- **然后** 渲染为流程图/时序图/类图
- **并且** 支持导出为图片

### 需求4: ZIP文件解析

系统应支持ZIP文件上传和代码库结构解析。

#### 场景4.1: ZIP上传
- **当** 用户上传ZIP文件
- **然后** 解析文件结构
- **并且** 生成文件树展示
- **当** 用户点击文件
- **然后** 显示文件内容预览

#### 场景4.2: 代码库分析
- **当** 用户上传代码库ZIP
- **然后** 自动识别项目类型（Node.js、Python等）
- **并且** 提取关键文件（README、package.json等）
- **并且** 生成项目摘要

## 修改需求

### 需求5: 优化网页内容提取

**修改内容**：增强现有的 WebContentExtractor，参考 All-Model-Chat 的实现

- 改进内容评分算法
- 优化HTML到Markdown的转换
- 添加更多元数据提取（Open Graph、Twitter Card等）
- 提升处理速度和准确性

## 技术要求

### URL抓取
- 使用现有的 `/api/read` 端点
- 实现客户端URL缓存（IndexedDB）
- 支持并发抓取多个URL
- 超时处理：默认10秒

### 搜索集成
- 支持 Google Custom Search API 或类似服务
- 实现搜索任务队列
- 结果去重和相关性排序
- 引用格式：[^1^] 样式

### Canvas渲染
- 使用 iframe 沙箱渲染HTML/CSS/JS
- ECharts使用CDN加载
- Mermaid使用CDN加载
- 支持深色/浅色主题切换

### ZIP解析
- 使用 JSZip 库解析ZIP
- 文件大小限制：50MB
- 支持文本文件预览（代码、Markdown等）
- 二进制文件显示下载选项

## 性能要求

- URL抓取响应时间 < 5秒（缓存命中 < 100ms）
- Canvas渲染首屏时间 < 1秒
- ZIP解析支持最大1000个文件
- 搜索结果显示时间 < 3秒

## 安全要求

- URL抓取遵循CORS策略
- Canvas渲染使用iframe沙箱（sandbox="allow-scripts"）
- ZIP文件类型白名单验证
- 防止XSS攻击（内容转义）
