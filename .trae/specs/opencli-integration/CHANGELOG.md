# OpenCLI 扩展程序 - 更新日志

## [2.0.0] - 2026-04-03

### 🎨 重大更新 - UX 全面优化

#### 新增功能

1. **增强的状态反馈系统**
   - 颜色编码状态栏 (绿色/黄色/红色)
   - 详细的状态提示信息
   - 执行状态指示器 (就绪/执行中/成功/错误)
   - 实时状态更新

2. **快速入门指引**
   - 4 步式教学引导新用户
   - 实际操作示例展示
   - 渐变背景和图标设计
   - 代码高亮显示

3. **按钮参数提示**
   - 每个按钮显示所需参数
   - 清晰的参数类型说明
   - 减少用户猜测

4. **优化的输入框**
   - 详细的 placeholder 示例
   - 必需/可选标签
   - MDN 文档帮助链接
   - 多行示例文本

5. **增强的执行按钮**
   - 全宽大按钮设计
   - 播放图标 + 文字
   - 悬停动画效果
   - 禁用状态显示

6. **清晰的区域分组**
   - 状态指示器区域
   - 快速入门区域
   - 页面操作区域
   - 高级操作区域
   - 快速命令区域
   - 输入区域
   - 执行按钮区域

## [1.0.0] - 2026-04-03

### 🎉 首次发布 - OpenCLI 深度集成

#### 核心功能

1. **OpenCLI 技能包装器**
   - 13 个浏览器自动化方法
   - 完整的 TypeScript 类型定义
   - 单例模式实现

2. **智能路由系统**
   - 页面复杂度评估 (0-100 分)
   - 3 种提取策略自动选择
   - 性能统计和日志

3. **可视化反馈**
   - 元素高亮显示
   - Toast 消息提示
   - 状态指示器
   - 操作反馈

4. **脚本录制回放**
   - 8 种操作类型录制
   - 脚本管理 (CRUD)
   - JSON 导出/导入
   - 回放功能

5. **会话管理**
   - 会话 CRUD 操作
   - XOR 加密存储
   - 过期检查 (30 天)
   - 安全审计日志

6. **协同工作流**
   - 与 WebContentExtractor 集成
   - 混合策略支持
   - 统一错误处理

#### UI 集成

- OpenCLI 操作面板
- 8 个控制按钮
- 3 个快速命令
- Selector 输入框
- Value 文本框
- 执行按钮

#### 测试覆盖

- 6 个测试文件
- 75 个测试用例
- 100% 通过率
- 完整的测试报告

#### 文档系统

- 19 个文档文件
- ~126KB 文档内容
- 从入门到精通全覆盖
