## 📊 技术实现

### 架构设计

```
Side Panel
    │
    ├─→ QueuePanel (队列面板)
    │   ├─ openCLIQueue (命令队列)
    │   ├─ 事件监听
    │   └─ 自动更新 (2 秒)
    │
    └─→ HistoryViewer (历史查看器)
        ├─ openCLIHistory (历史记录)
        ├─ 搜索过滤
        ├─ 分页
        └─ 导出功能
```

### 关键技术点

#### 1. **事件驱动更新**

```typescript
// 队列事件监听
openCLIQueue.on('command:added', () => this.renderQueue());
openCLIQueue.on('command:completed', () => this.renderQueue());
openCLIQueue.on('queue:started', () => this.updateStatus('执行中...'));
```

#### 2. **自动刷新机制**

```typescript
// 每 2 秒自动更新队列显示
private startAutoUpdate(): void {
  this.updateTimer = window.setInterval(() => {
    this.renderQueue();
  }, 2000);
}
```

#### 3. **分页实现**

```typescript
// 分页逻辑
const offset = (this.currentPage - 1) * this.pageSize;
const history = openCLIHistory.query({
  limit: this.pageSize,
  offset,
});
```

#### 4. **状态管理**

```typescript
// 优先级和状态映射
private getPriorityClass(priority: number): string {
  switch (priority) {
    case CommandPriority.CRITICAL: return 'priority-critical';
    case CommandPriority.HIGH: return 'priority-high';
    // ...
  }
}
```

## 📚 使用指南

### 使用队列管理面板

1. **查看队列**
   - 打开扩展侧边栏
   - 点击 OpenCLI 按钮
   - 滚动到底部查看队列面板

2. **控制队列**
   - 点击"开始"执行队列
   - 点击"暂停"暂停执行
   - 点击"停止"停止执行
   - 点击"🗑️"清空队列

3. **管理命令**
   - ⬆️⬇️ 上移/下移命令
   - ✏️ 编辑命令参数
   - 🗑️ 删除命令

### 使用历史记录查看器

1. **查看历史**
   - 打开扩展侧边栏
   - 点击 OpenCLI 按钮
   - 滚动查看历史记录

2. **搜索过滤**
   - 输入关键词搜索
   - 选择命令类型
   - 选择执行结果
   - 选择时间范围

3. **导出历史**
   - 点击"导出"按钮
   - 选择保存位置
   - 打开 CSV 文件

4. **重放命令**
   - 找到目标历史
   - 点击"重放"按钮
   - 查看执行结果
