# 🔧 一键提取故障排除指南

## ❌ 常见错误及解决方案

### 错误 1: "Could not establish connection. Receiving end does not exist"

**错误信息**:
```
提取失败：Could not establish connection. Receiving end does not exist.
```

**原因**:
- 内容脚本（content-script.js）尚未加载到页面中
- 页面刚加载时，内容脚本可能还未注入

**解决方案**:

#### ✅ 自动修复（已实现）

系统现在会自动处理这个错误：

1. **检测到错误** → 系统捕获到 "Receiving end does not exist" 错误
2. **自动注入** → 使用 `chrome.scripting.executeScript` API 注入内容脚本
3. **等待加载** → 等待 1 秒让脚本加载
4. **重试提取** → 重新发送消息提取内容
5. **显示提示**:
   - "正在注入内容脚本..."（2 秒）
   - "内容脚本已注入，继续提取..."（2 秒）

**用户操作**:
- 等待自动修复完成（约 3-5 秒）
- 无需任何手动操作

#### 🔧 手动修复

如果自动修复失败：

1. **刷新页面**
   ```
   按 F5 或 Ctrl+R 刷新页面
   ```

2. **等待页面完全加载**
   ```
   等待 1-2 秒，确保内容脚本加载完成
   ```

3. **重新点击"⚡ 一键提取"按钮**

### 错误 2: "注入内容脚本失败，请刷新页面后重试"

**错误信息**:
```
注入内容脚本失败，请刷新页面后重试
```

**原因**:
- 页面是特殊页面（chrome://, about:, file:// 等）
- 页面不允许注入内容脚本
- 扩展权限不足

**解决方案**:

1. **检查页面类型**
   ```
   ❌ 不支持的页面：
   - chrome://extensions
   - chrome://settings
   - about:blank
   - file:///C:/...
   - edge://...
   
   ✅ 支持的页面：
   - https://...
   - http://... (大多数)
   ```

2. **刷新页面**
   ```
   按 F5 刷新页面
   ```

3. **检查扩展权限**
   ```
   1. 右键点击扩展图标
   2. 选择"管理扩展"
   3. 确保"允许访问文件 URL"已启用（如果需要访问本地文件）
   4. 确保"读取和更改您在所有网站上的数据"权限已启用
   ```

### 错误 3: "当前页面不支持提取"

**错误信息**:
```
当前页面不支持提取
```

**原因**:
- 页面 URL 在不支持的列表中
- 页面是浏览器内部页面

**解决方案**:

1. **检查 URL**
   ```javascript
   不支持的 URL 前缀：
   - chrome://
   - chrome-extension://
   - edge://
   - about:
   - file://
   ```

2. **打开普通网页**
   ```
   导航到 https:// 开头的网页
   例如：https://news.ycombinator.com
   ```

---

### 错误 4: "网页内容为空"

**错误信息**:
```
网页内容为空
```

**原因**:
- 页面使用动态加载（如 React、Vue、Angular）
- 页面需要滚动才能加载内容
- 页面需要登录才能查看内容

**解决方案**:

#### 方案 1: 等待页面完全加载
```
1. 等待 2-3 秒
2. 确保所有动态内容已加载
3. 重新点击"⚡ 一键提取"
```

#### 方案 2: 手动滚动页面
```
1. 向下滚动页面，触发懒加载
2. 滚动到页面底部
3. 再滚动回顶部
4. 点击"⚡ 一键提取"
```

#### 方案 3: 使用"读网页"按钮（高级选项）
```
1. 点击"读网页"按钮（不是一键提取）
2. 在配置面板中启用：
   - ✅ 自动滚动
   - ✅ 等待动态内容
   - ✅ 增加滚动步数
3. 点击"开始读取"
```

### 错误 5: "读取网页失败"

**错误信息**:
```
读取网页失败
```

**原因**:
- 内容脚本执行错误
- 页面结构复杂
- 页面有反爬虫机制

**解决方案**:

1. **检查浏览器控制台**
   ```
   1. 按 F12 打开开发者工具
   2. 切换到 Console 标签
   3. 查看是否有红色错误信息
   4. 记录错误信息
   ```

2. **尝试其他页面**
   ```
   测试简单页面：
   https://example.com
   https://news.ycombinator.com
   ```

3. **使用备用方法**
   ```
   1. 复制页面 URL
   2. 在 AI 对话框中输入：
      "请帮我读取这个网页的内容：[URL]"
   ```

### 错误 6: "获取 AI 回复失败"

**错误信息**:
```
获取 AI 回复失败
```

**原因**:
- AI 服务未配置
- AI 服务不可用
- 网络连接问题
- 内容太长超出限制

**解决方案**:

#### 方案 1: 检查 AI 配置
```
1. 点击扩展图标
2. 点击"设置"
3. 检查 AI 服务配置：
   - API URL 是否正确
   - API Key 是否有效
   - 模型名称是否正确
```

#### 方案 2: 检查网络连接
```
1. 检查网络连接是否正常
2. 尝试访问 AI 服务提供商网站
3. 检查防火墙设置
```

#### 方案 3: 减少内容长度
```
1. 使用"读网页"按钮
2. 减少最大字符数限制
3. 只提取关键部分
```

   ```

   2. 右键点击侧边栏任意位置
   ```

   ```
   1. 按 F12 打开开发者工具
   2. 切换到 Console 标签

   ```

3. **查看后台脚本日志**
   ```
   1. 导航到 chrome://extensions/
   2. 找到扩展
   3. 点击"查看视图：Service Worker"
   4. 打开开发者工具查看日志
   ```

### 测试内容脚本

1. **手动测试内容脚本**
   ```javascript
   // 在页面控制台中执行
   chrome.runtime.sendMessage({ type: 'readPage' }, response => {
     console.log('Response:', response);
   });
   ```

2. **检查内容脚本是否加载**
   ```javascript
   // 在页面控制台中执行
   console.log('Content script loaded:', typeof window.contentScript !== 'undefined');
   ```

## 📊 性能优化

### 提高提取速度

1. **减少内容长度**
   ```
   修改代码中的 maxChars 参数：
   maxChars: 60_000, // 减少为 60k
   ```

2. **禁用不必要的选项**
   ```
   extractLinkUrl: false,  // 不提取链接
   extractImageUrl: false, // 不提取图片
   maxUrls: 50,           // 减少 URL 数量
   ```

3. **减少滚动次数**
   ```
   scrollSteps: 5,    // 减少滚动步数
   scrollDelayMs: 100, // 减少滚动延迟
   ```

### 提高成功率

1. **增加等待时间**
   ```
   settleDelayMs: 1500, // 增加稳定延迟
   ```

2. **增加滚动次数**
   ```
   scrollSteps: 15,     // 增加滚动步数
   scrollDelayMs: 300,  // 增加滚动延迟
   ```

3. **启用递归提取**
   ```
   recursiveSameDomain: true, // 递归提取同域名页面
   ```

## 🆘 紧急处理

### 如果所有方法都失败

1. **重启浏览器**
   ```
   1. 关闭所有浏览器窗口
   2. 重新打开浏览器
   3. 重新加载扩展
   ```

2. **重新加载扩展**
   ```
   1. 导航到 chrome://extensions/
   2. 找到扩展
   3. 点击刷新按钮
   4. 重新打开页面
   ```

3. **清除扩展数据**
   ```
   1. 导航到 chrome://extensions/
   2. 找到扩展
   3. 点击"清除数据"
   4. 重新配置扩展
   ```

4. **重新安装扩展**
   ```
   1. 卸载扩展
   2. 删除扩展文件夹
   3. 重新编译扩展
   4. 重新安装扩展
   ```
