# 🖥️ OpenCLI 控制台日志显示功能

## 🎯 功能概述

为 OpenCLI 命令执行添加了详细的控制台日志输出，方便调试和查看执行过程。

**启用位置**: 网页开发者工具控制台（F12 → Console）

---

## 🎨 日志格式说明

### 日志分组

使用 `console.group()` 将相关日志组织在一起：

- **🔧 OpenCLI 命令** - 单个命令执行详情
- **🚀 OpenCLI 执行** - 后台脚本执行入口
- **📦 OpenCLI 批量执行** - 批量命令执行

### 图标含义

| 图标 | 含义 |
|------|------|
| 🔧 | 命令执行详情 |
| 🚀 | 后台脚本执行入口 |
| 📦 | 批量执行 |
| 📝 | 参数信息 |
| ⏱️ | 时间信息 |
| ✅ | 成功 |
| ❌ | 失败 |
| 🔄 | 缓存状态 |
| 📡 | 网络请求 |
| 📊 | 返回数据 |
| ⚡ | 快速操作 |
| 💡 | 提示信息 |

## 🔍 查看方法

### 步骤 1: 打开开发者工具

1. 在任意网页按 `F12` 或 `Ctrl+Shift+I`
2. 切换到 **Console** 标签

### 步骤 2: 执行 OpenCLI 命令

通过以下方式执行命令：
- AI 对话框输入命令
- 点击"⚡ 一键提取"按钮
- 使用 OpenCLI 面板

### 步骤 3: 查看日志

在控制台中查看带有图标的结构化日志

## 📋 日志级别

### Info 级别（普通信息）
```
📝 参数
⏱️ 开始时间
🔄 缓存状态
✅ 守护进程状态
📡 发送请求
```

### Success 级别（成功）
```
✅ 执行成功
📊 返回数据
⏱️ 总耗时
```

### Error 级别（错误）
```
❌ 参数验证失败
❌ 守护进程未运行
❌ 执行失败
❌ 命令执行异常
```

### Warning 级别（警告）
```
⚠️ Bridge 执行失败，使用备用方案
```

## 🛠️ 日志内容详解

### 1. 命令执行前

```
🔧 OpenCLI 命令：{command}
  📝 参数：{args}
  ⏱️ 开始时间：{timestamp}
```

**包含信息**:
- 命令名称
- 命令参数（JSON 格式）
- 执行开始时间

### 2. 缓存检查

```
✅ 使用缓存结果
  ⚡ 耗时：0ms (缓存)
```

或

```
🔄 缓存未命中，执行实际命令
```

### 3. 守护进程状态

```
✅ 守护进程状态：运行中
```

或

```
❌ 守护进程未运行
💡 提示：请先启动 OpenCLI CLI
```

### 4. 网络请求

```
📡 发送请求到 OpenCLI 服务器...
```

### 5. 执行结果

**成功**:
```
✅ 执行成功
📊 返回数据：{data}
⏱️ 总耗时：{duration}ms
```

**失败**:
```
❌ 执行失败
  错误代码：{error}
  错误信息：{message}
⏱️ 总耗时：{duration}ms
```

## 🔧 自定义日志

### 修改日志级别

在代码中控制日志输出：

```typescript
// 在 opencli-bridge.ts 中
const DEBUG_MODE = true; // 设置为 false 禁用调试日志

if (DEBUG_MODE) {
  console.log('🔧 Debug info...');
}
```

### 添加自定义日志

在关键位置添加日志：

```typescript
console.log('💡 自定义信息');
console.error('❌ 自定义错误');
console.warn('⚠️ 自定义警告');
```

## ⚠️ 注意事项

### 1. 隐私保护

日志中可能包含敏感信息：
- 页面内容
- 用户输入
- 认证信息

**建议**: 在公共场合分享日志时，先删除敏感信息

### 2. 日志数量

复杂操作可能产生大量日志

**建议**: 使用日志过滤功能，只看关心的内容

### 3. 浏览器性能

大量日志可能影响浏览器性能

**建议**: 定期清理控制台

## 🆚 与其他日志的区别

### OpenCLI 控制台日志 vs 后台脚本日志

| 特性 | OpenCLI 控制台日志 | 后台脚本日志 |
|------|-------------------|-------------|
| 位置 | 网页控制台 | 后台脚本控制台 |
| 格式 | 结构化、带图标 | 普通文本 |
| 详细程度 | 非常详细 | 相对简洁 |
| 适用场景 | 调试、学习 | 监控、排查 |

### OpenCLI 控制台日志 vs Logger

| 特性 | OpenCLI 控制台日志 | Logger |
|------|-------------------|--------|
| 输出位置 | 浏览器控制台 | 文件/控制台 |
| 格式 | 可视化、带图标 | 文本 |
| 实时性 | 实时显示 | 可延迟 |
| 持久化 | 否 | 是 |
