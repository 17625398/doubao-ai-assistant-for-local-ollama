## 🚀 升级指南

### 对于新用户

1. **安装 OpenCLI**
   ```bash
   npm install -g @jackwener/opencli@1.6.1
   ```

2. **构建扩展程序**
   ```bash
   cd packages/extension
   npm run build
   ```

3. **加载扩展**
   - 打开浏览器扩展管理
   - 加载已解压的扩展程序
   - 选择 `packages/extension/dist`

### 对于现有用户

1. **重新构建**
   ```bash
   npm run build:extension
   ```

2. **重新加载**
   - 在扩展管理页面点击"重新加载"
   - 或按 Ctrl+R 刷新侧边栏

3. **体验新功能**
   - 打开侧边栏
   - 查看新的 UI
   - 享受更好的体验
