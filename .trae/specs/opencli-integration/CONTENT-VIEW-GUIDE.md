# OpenCLI 内容提取查看指南

## 📍 提取内容的显示位置

当您使用 OpenCLI 执行内容提取命令后，提取的内容会显示在以下位置：

---

## 1️⃣ **执行结果面板** (主要显示位置)

### 位置
- 在 OpenCLI 主面板的**命令执行区域下方**
- 在"执行操作"按钮的下方

### 显示格式
```
┌─────────────────────────────────────┐
│  📊 执行结果            [📋 复制]   │
├─────────────────────────────────────┤
│  这里是提取的内容...                │
│                                     │
│  提取的文本内容会显示在这里         │
│  支持多行显示                       │
│  ...                                │
└─────────────────────────────────────┘
```

### 如何触发显示
1. 打开扩展侧边栏
2. 点击 "OpenCLI" 按钮
3. 选择命令（如"获取元素"）
4. 输入选择器（如 `h1` 或 `.content`）
5. 点击"执行操作"
6. **结果立即显示在按钮下方**

---

## 2️⃣ **队列管理面板** (队列执行结果)

### 位置
- 在 OpenCLI 面板的**底部区域**
- 队列项的详情中

### 查看方式
```
队列项 → 执行完成 → 显示结果
┌─────────────────────────────────────┐
│  1. [HIGH] get → .content           │
│     状态：完成 ✅                    │
├─────────────────────────────────────┤
│  📊 执行结果：                      │
│  这里是提取的内容...                │
│  (可滚动查看完整内容)               │
└─────────────────────────────────────┘
```

### 访问步骤
1. 打开 OpenCLI 面板
2. 滚动到底部
3. 找到"命令队列"面板
4. 查看已完成命令的结果

---

## 3️⃣ **历史记录查看器** (历史提取记录)

### 位置
- 在 OpenCLI 面板的**最底部**
- 历史记录列表中

### 查看方式
```
┌─────────────────────────────────────┐
│  📜 执行历史            [📤 导出]   │
├─────────────────────────────────────┤
│  #1  ✅  10:23:45                   │
│  get                                │
│  {selector: '.content'}             │
│  ⏱️ 125ms                           │
│  [查看详情] [重放]                  │
└─────────────────────────────────────┘
```

### 访问步骤
1. 打开 OpenCLI 面板
2. 滚动到最底部
3. 找到"执行历史"面板
4. 点击任意历史记录的"查看详情"按钮
5. 在弹窗中查看完整的提取内容

### 导出历史
1. 点击"导出"按钮
2. 保存 CSV 文件
3. 用 Excel 或其他工具打开查看

## 🔍 快速定位提取内容

### 方法 1: 使用搜索
```
1. 打开历史记录查看器
2. 在搜索框输入关键词
3. 过滤出相关的提取记录
4. 点击查看详情
```

### 方法 2: 按命令类型过滤
```
1. 打开历史记录查看器
2. 在"命令"下拉框选择"get"或"extract.content"
3. 只显示内容提取相关的记录
4. 点击查看详情
```

### 方法 3: 按时间范围
```
1. 打开历史记录查看器
2. 在"时间"下拉框选择时间范围
3. 快速定位最近的提取记录
```

## 💡 常见问题

### Q1: 执行命令后看不到结果？

**可能原因**:
- 结果面板被折叠或未展开
- 提取内容为空
- 命令执行失败

**解决方案**:
```
1. 检查命令执行状态（是否显示"执行成功"）
2. 查看是否有错误提示
3. 滚动到执行按钮下方查看结果面板
4. 检查选择器是否正确
```

### Q2: 结果太多看不到完整内容？

**解决方案**:
```
1. 结果面板支持滚动
2. 鼠标悬停在结果区域
3. 使用滚轮或拖动滚动条
4. 或点击"复制"按钮复制到剪贴板
```

### Q3: 如何保存提取的内容？

**方法 1: 复制粘贴**
```
1. 点击结果面板右上角的"📋 复制"按钮
2. 粘贴到文本编辑器或文档中
```

**方法 2: 导出历史**
```
1. 打开历史记录查看器
2. 点击"📤 导出"按钮
3. 保存 CSV 文件
4. 用 Excel 打开查看和编辑
```

**方法 3: 截图保存**
```
1. 使用截图工具
2. 截取结果面板
3. 保存为图片
```

## 📋 完整操作流程示例

### 示例 1: 提取文章标题

```
步骤 1: 打开网页
   → 访问包含文章的网页

步骤 2: 打开扩展
   → 点击浏览器工具栏的扩展图标

步骤 3: 打开 OpenCLI
   → 点击 "OpenCLI" 按钮

步骤 4: 选择命令
   → 点击 "获取元素" 按钮

步骤 5: 输入选择器
   → 在"选择器"输入框输入：h1 或 .article-title

步骤 6: 执行
   → 点击 "执行操作" 按钮

步骤 7: 查看结果
   → 结果立即显示在按钮下方
   → 格式：
      ┌─────────────────────┐
      │ 📊 执行结果  [📋]   │
      ├─────────────────────┤
      │ 文章标题内容        │
      └─────────────────────┘

步骤 8: 复制保存
   → 点击"📋"按钮复制
   → 粘贴到需要的地方
```

### 示例 2: 提取页面正文内容

```
步骤 1-3: 同上

步骤 4: 选择命令
   → 点击 "提取页面内容" 按钮
   → 或选择"获取元素"手动输入选择器

步骤 5: 输入选择器
   → 输入：article 或 .content 或 main

步骤 6-8: 同上

查看历史:
   → 滚动到面板底部
   → 在"执行历史"中找到记录
   → 点击"查看详情"再次查看
```

## 📊 内容存储位置

### 临时存储（当前会话）
- **位置**: 浏览器内存
- **特点**: 关闭扩展后清除
- **用途**: 即时查看和复制

### 持久存储（历史记录）
- **位置**: Chrome Storage Local
- **路径**: `opencli_history`
- **特点**: 永久保存，除非手动清除
- **用途**: 历史查询和导出

### 导出文件
- **格式**: CSV
- **位置**: 用户选择的下载目录
- **特点**: 可用 Excel 编辑
- **用途**: 数据分析和存档

## 🔧 故障排查

### 问题：找不到结果面板

**检查清单**:
- [ ] 命令是否执行成功（查看状态提示）
- [ ] 是否滚动了页面（结果在按钮下方）
- [ ] 结果是否为空（提取失败）
- [ ] 是否有错误消息

### 问题：历史记录为空

**可能原因**:
- 刚加载扩展，历史尚未同步
- 历史记录被清空
- 存储权限问题

**解决方案**:
```
1. 刷新扩展页面
2. 重新执行命令
3. 检查扩展权限设置
```

## 📞 获取帮助

如果仍然找不到提取的内容，请检查：

1. **OpenCLI CLI 是否运行**
   ```bash
   opencli daemon status
   ```

2. **扩展是否正确加载**
   - 访问 `chrome://extensions/`
   - 确认扩展已启用

3. **查看控制台日志**
   - 按 F12 打开开发者工具
   - 查看 Console 标签
   - 查找错误信息

4. **查看性能监控**
   - 打开 OpenCLI 面板
   - 查看性能监控面板
   - 检查命令执行记录
