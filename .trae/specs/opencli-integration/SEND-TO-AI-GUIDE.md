# 发送到 AI 功能使用指南

## 🎯 功能概述

"发送到 AI"功能允许您一键将 OpenCLI 提取的内容直接发送到 AI 对话输入框，并自动附加页面上下文信息（标题、URL、选择器等）。

## ✨ 功能特性

### 1. 智能上下文构建

当您点击"发送到 AI"按钮时，系统会自动构建包含以下信息的智能提示：

- 📄 **页面标题** - 当前网页的标题
- 🔗 **URL** - 当前网页的地址
- 🎯 **选择器** - 提取内容使用的 CSS 选择器（如果有）
- 📝 **提取内容** - OpenCLI 返回的实际内容

### 2. 一键发送

无需手动复制粘贴，点击按钮即可自动填充 AI 输入框。

### 3. 友好的用户提示

系统会显示 Toast 通知，告知内容已填充到输入框，请确认后发送。

## 📖 使用步骤

### 步骤 1: 执行 OpenCLI 提取命令

在 AI 对话框中输入类似以下的命令：

```
读取网页 https://example.com 的 .article-content 内容
```

或使用快速命令按钮。

### 步骤 2: 查看提取结果

执行完成后，结果会显示在 OpenCLI 面板中：

```
┌─────────────────────────────────────┐
│ 📊 执行结果                         │
│ ┌─────────────────────────────────┐ │
│ │ [提取的内容显示在这里]          │ │
│ └─────────────────────────────────┘ │
│ 选择器：.article-content            │
└─────────────────────────────────────┘
```

### 步骤 3: 点击发送到 AI 按钮

在结果面板右上角，您会看到两个按钮：
- 📋 **复制按钮** - 复制内容到剪贴板
- 💬 **发送到 AI 按钮** - 发送到 AI 输入框

点击 💬 按钮。

### 步骤 4: 确认并发送

AI 输入框会自动填充以下内容：

```
📄 页面：Example Domain
🔗 URL: https://example.com
🎯 选择器：.article-content

📝 提取内容:
[提取的内容]

请帮我分析/总结/处理以上内容。
```

检查无误后，按 Enter 或点击发送按钮即可。

## 🔧 技术细节

### 智能提示生成逻辑

```typescript
// 1. 获取当前页面信息
const [tab] = await chrome.tabs.query({ 
  active: true, 
  currentWindow: true 
});

// 2. 构建提示
let message = '';
if (tab?.title) {
  message += `📄 页面：${tab.title}\n`;
}
if (tab?.url) {
  message += `🔗 URL: ${tab.url}\n`;
}
if (selector) {
  message += `🎯 选择器：${selector}\n\n`;
}
message += `📝 提取内容:\n${content}\n\n`;
message += `请帮我分析/总结/处理以上内容。`;
```

### 剪贴板复制逻辑

支持两种方式：
1. **Clipboard API** (现代浏览器)
   ```typescript
   await navigator.clipboard.writeText(text);
   ```

2. **Fallback** (旧浏览器)
   ```typescript
   const textarea = document.createElement('textarea');
   textarea.value = text;
   document.body.appendChild(textarea);
   textarea.select();
   document.execCommand('copy');
   document.body.removeChild(textarea);
   ```

## ⚠️ 注意事项

1. **输入框焦点**: 发送后内容会填充到 AI 输入框，但需要您手动确认发送
2. **内容长度**: 如果提取内容过长，可能会被 AI 模型的上下文长度限制
3. **页面权限**: 需要当前标签页的访问权限以获取标题和 URL
4. **剪贴板权限**: 复制功能需要浏览器剪贴板权限

## 🐛 故障排除

### 问题 1: 点击按钮后没有反应

**解决方案**:
- 检查 AI 输入框是否存在
- 查看浏览器控制台是否有错误
- 刷新扩展程序后重试

### 问题 2: 内容没有正确填充

**解决方案**:
- 确保使用的是最新版本的扩展
- 检查是否有其他脚本干扰
- 尝试手动复制粘贴

### 问题 3: 复制功能失效

**解决方案**:
- 检查浏览器剪贴板权限
- 确保页面不是特殊页面（如 chrome://）
- 尝试使用快捷键 Ctrl+C 手动复制

## 🎓 最佳实践

1. **明确目标**: 在提取前先想好要让 AI 做什么
2. **精确选择器**: 使用精确的 CSS 选择器，避免提取无关内容
3. **分步处理**: 对于复杂任务，分多次提取和发送
4. **上下文管理**: 在多轮对话中，适时提醒 AI 之前的上下文
5. **内容验证**: 发送前快速浏览填充的内容，确保准确性
