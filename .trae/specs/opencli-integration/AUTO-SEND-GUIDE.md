# 🚀 自动化发送功能使用指南

## ⚡ 快速开始

### 什么是自动化发送？

以前需要点击 4 次才能完成的操作，现在只需要**点击 1 次**！

### 对比演示

#### ❌ 旧流程（需要 4 步）
```
1. 点击"发送到 AI"按钮
2. 内容填充到输入框
3. 您检查内容
4. 您点击"发送"按钮
```

#### ✅ 新流程（只需 1 步）
```
1. 点击"发送到 AI"按钮
   ↓
   [系统自动完成：填充 → 发送 → 获取回复]
   ↓
2. 直接查看 AI 回复！
```

## 📖 使用步骤

### 步骤 1: 执行 OpenCLI 命令

在 AI 对话框中输入：
```
读取网页 https://github.com/trending 的 .Box-row 内容
```

或使用快速命令按钮。

### 步骤 2: 点击"发送到 AI"按钮

执行完成后，结果面板会显示：

```
┌─────────────────────────────────────┐
│ 📊 执行结果        [📋] [💬]        │
│                                     │
│ [提取的内容...]                     │
│                                     │
└─────────────────────────────────────┘
```

点击 **💬** 按钮（绿色渐变）。

### 步骤 3: 等待 AI 回复

点击后会发生什么？

```
时间线：
0ms    - 您点击了按钮
0-300ms  - 系统构建智能提示（包含页面标题、URL、选择器）
300ms   - 内容填充到输入框
300-500ms - 系统自动点击发送
500ms+  - AI 开始处理并回复
```

您会看到两个提示：
1. "正在发送到 AI..."（2 秒）
2. "已自动发送到 AI"（3 秒）

### 步骤 4: 查看 AI 回复

AI 的回复会自动出现在对话框中！

## ⚙️ 功能说明

### 自动发送的工作原理

```typescript
点击按钮
  ↓
构建智能提示（页面信息 + 提取内容）
  ↓
填充到 AI 输入框
  ↓
延迟 300ms（确保 UI 更新）
  ↓
调用 sendMessage()
  ↓
清空输入框
  ↓
显示加载动画
  ↓
发送请求到 AI
  ↓
显示 AI 回复
  ↓
完成！
```

### 智能提示包含什么？

每次自动发送时，系统会自动构建如下提示：

```
📄 页面：GitHub Trending
🔗 URL: https://github.com/trending
🎯 选择器：.Box-row

📝 提取内容:
[实际提取的内容]

请帮我分析/总结/处理以上内容。
```

## 🔧 高级用法

### 手动模式（可选）

如果您想先检查内容再发送，可以：

1. **临时手动模式**：
   - 点击按钮后，内容会填充到输入框
   - 但不自动发送（需要修改代码设置 `autoSend: false`）

2. **使用复制按钮**：
   - 点击 📋 按钮复制内容
   - 手动粘贴到输入框
   - 自己编辑后再发送

### 批量处理

```
1. 提取页面 A → 点击 💬 → 获取分析
2. 提取页面 B → 点击 💬 → 获取分析
3. 提取页面 C → 点击 💬 → 获取分析

```

## ❓ 常见问题

### Q1: 我能取消自动发送吗？

**A**: 目前自动发送是默认启用的。如果您想先检查内容，可以：
- 使用 📋 复制按钮，然后手动粘贴
- 或者在代码中将 `autoSend` 参数设为 `false`

### Q2: 自动发送会不会发送错误的内容？

**A**: 不会。系统在发送前会：
1. 构建完整的智能提示（包含页面信息）
2. 填充到输入框（您可以看到）
3. 延迟 300ms 确保 UI 更新
4. 然后才发送

### Q3: 如果 AI 没有回复怎么办？

**A**: 如果 AI 没有回复，可能是：
1. 网络连接问题
2. AI 服务不可用
3. 内容太长超出限制

解决方法：
- 检查网络连接
- 检查 AI 配置
- 尝试发送更短的内容

### Q4: 能自定义自动发送的提示吗？

**A**: 可以！修改 `sendToAI()` 方法中的提示构建逻辑：

```typescript
// 自定义提示
message += `请帮我${您的自定义指令}`;
```

## 💡 最佳实践

### ✅ 推荐做法

1. **明确目标** - 在提取前先想好要让 AI 做什么
2. **精确选择器** - 使用精确的 CSS 选择器
3. **分步处理** - 复杂任务分多次提取
4. **利用自动化** - 充分利用自动发送节省时间

### ❌ 避免做法

1. **不要** 提取大段无关内容
2. **不要** 在自动发送时频繁点击按钮
3. **不要** 完全依赖自动化而不检查结果
