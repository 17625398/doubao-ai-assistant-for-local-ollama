# OpenCLI 扩展程序 - 使用指南

## 🚀 快速开始

### 第 1 步：确保 OpenCLI 已安装

```bash
# 检查是否已安装
opencli --version

# 如果未安装，执行:
npm install -g @jackwener/opencli@1.6.1
```

### 第 2 步：打开扩展程序侧边栏

1. 点击浏览器工具栏中的扩展图标
2. 点击 "OpenCLI" 按钮展开面板

### 第 3 步：检查状态

查看顶部状态栏:
- ✅ **绿色** - OpenCLI 已就绪，可以使用
- ⚠️ **黄色** - 正在检测
- ❌ **红色** - 未就绪，请检查安装

## 📖 基本操作

### 操作 1: 打开网页

1. 点击 "🔗 打开" 按钮
2. 在"CSS 选择器"输入框输入 URL
   ```
   https://www.example.com
   ```
3. 点击 "执行操作"

### 操作 2: 点击元素

1. 点击 "👆 点击" 按钮
2. 在"CSS 选择器"输入框输入元素选择器
   ```
   #login-btn
   ```
3. 点击 "执行操作"

### 操作 3: 输入文本

1. 点击 "⌨️ 输入" 按钮
2. 在"CSS 选择器"输入框输入输入框选择器
   ```
   #username
   ```
3. 在"值/脚本"输入框输入文本
   ```
   hello@example.com
   ```
4. 点击 "执行操作"

### 操作 4: 获取内容

1. 点击 "📄 获取" 按钮
2. 在"CSS 选择器"输入框输入元素选择器
   ```
   h1
   ```
3. 点击 "执行操作"
4. 查看返回的内容

## 💡 进阶操作

### 截图

1. 点击 "📷 截图" 按钮
2. (可选) 在"值/脚本"输入框输入保存路径
   ```
   ./screenshot.png
   ```
3. 点击 "执行操作"

### 执行 JavaScript

1. 点击 "💻 执行 JS" 按钮
2. 在"值/脚本"输入框输入 JavaScript 代码
   ```javascript
   document.title
   ```
3. 点击 "执行操作"
4. 查看执行结果

### 滚动页面

1. 点击 "📜 滚动" 按钮
2. 在"值/脚本"输入框输入方向和距离
   ```
   down, 500
   ```
3. 点击 "执行操作"

## 🎯 CSS 选择器示例

### 常用选择器

```css
/* ID 选择器 */
#login-btn

/* 类选择器 */
.submit-button

/* 标签选择器 */
input[type="text"]

/* 属性选择器 */
a[href="/home"]

/* 组合选择器 */
form#login input.password

/* 伪类选择器 */
button:hover
```

### 如何查找选择器

1. **浏览器开发者工具**
   - 右键点击元素 → "检查"
   - 在 Elements 面板查看元素
   - 右键元素 → Copy → Copy selector

2. **MDN 文档**
   - 点击 "❓ 如何选择器？" 链接
   - 查看完整的 CSS 选择器教程

## ❓ 常见问题

### Q: 显示"OpenCLI 未就绪"怎么办？

**A:** 请按以下步骤检查:

1. 检查 OpenCLI 是否安装
   ```bash
   opencli --version
   ```

2. 检查 daemon 是否运行
   ```bash
   Test-NetConnection -ComputerName localhost -Port 19825
   ```

3. 重启 daemon
   ```bash
   taskkill /F /IM opencli.exe
   opencli daemon start
   ```

详细解决方案见 [OPENCLI-STATUS-FIX.md](./OPENCLI-STATUS-FIX.md)

### Q: 操作失败怎么办？

**A:** 检查以下几点:

1. **选择器是否正确**
   - 使用开发者工具验证选择器
   - 确保元素存在

2. **页面是否加载完成**
   - 等待页面完全加载
   - 使用"等待"操作

3. **查看错误信息**
   - 查看执行状态栏的错误提示
   - 检查浏览器控制台

### Q: 如何保存登录状态？

**A:** 使用快速命令:

1. 登录到目标网站
2. 点击 "🔑 提取登录状态"
3. 会话自动保存
4. 下次使用时加载会话即可

## 🎨 界面说明

### 状态栏
- **状态指示灯**: 显示连接状态
- **状态文本**: 当前状态描述
- **提示信息**: 额外提示

### 操作按钮
- **图标**: 直观表示操作类型
- **名称**: 操作名称
- **参数提示**: 需要的参数类型

### 输入框
- **标签**: 输入内容说明
- **必需/可选**: 是否必须填写
- **Placeholder**: 输入示例
- **帮助链接**: 相关文档

### 执行按钮
- **执行操作**: 执行当前操作
- **执行状态**: 显示执行进度
