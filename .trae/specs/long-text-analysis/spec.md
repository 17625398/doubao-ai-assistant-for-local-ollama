# 长文本分析和网页内容提取方法 - 产品需求文档

## 概述
- **摘要**：实现了长文本分析和网页内容提取功能，支持处理和分析大型文本文档以及从网页中提取结构化和非结构化信息，包括文本摘要、结构化信息提取、语义理解、情感分析等多种分析方法。已完成核心服务的实现，包括文本分块、网页内容提取、本地存储、文本摘要、结构化信息提取、JavaScript-heavy网页处理、多格式支持和多引擎统一调度等功能。
- **目的**：帮助用户更有效地处理和理解长文本内容，从网页中提取关键信息，发现文本中的模式和关系，提高文本分析和网页内容提取的效率和准确性。
- **目标用户**：研究人员、分析师、内容创作者、开发者等需要处理和分析长文本以及从网页中提取信息的用户。
- **实现状态**：核心服务已实现，支持基本的长文本分析和网页内容提取功能，可通过服务接口使用。

## 目标
- 支持处理大型文本文档（如长文章、报告、法律文件等）
- 提供多种文本分析方法，包括文本摘要、结构化信息提取、语义理解等
- 优化长文本处理的性能和准确性
- 提供直观的用户界面，方便用户进行长文本分析
- 支持多模态内容的分析（如文本、图片、视频等）

## 非目标（范围外）
- 不支持实时语音识别和分析
- 不提供云端存储和共享功能
- 不支持多语言翻译功能
- 不替代专业的文本分析工具（如学术研究工具）

## 背景与上下文
- 长文本分析是自然语言处理（NLP）的重要应用领域
- 随着大语言模型（LLM）的发展，长文本处理能力得到了显著提升
- 现有的长文本分析工具存在性能瓶颈和准确性问题
- 多模态内容的分析需求日益增长
- 网页内容提取是数据获取和分析的重要环节
- 现有的网页内容提取工具存在处理JavaScript-heavy网页的挑战
- 结合长文本分析和网页内容提取可以提供更全面的信息处理能力
- 现有平台需要增强长文本分析和网页内容提取能力，提供更全面的信息处理功能
- All-Model-Chat库提供了先进的长文本处理和网页内容提取功能，包括深度推理、高级文件处理、URL上下文抓取等
- 基于Gemini系列模型的思维链可视化和Token预算管理为长文本分析提供了新的思路
- 网络拦截器和API代理机制为网页内容提取提供了更灵活的实现方式
- SmartDoc-AI库提供了智能文档分析功能，包括多格式支持、智能摘要、结构化大纲、可视化思维导图、文档对话等
- 基于DeepSeek API的实现为长文本分析提供了另一种思路
- 文本清洗和正文提取引擎为网页内容提取提供了更有效的方法
- unified-web-skill库提供了统一的Web研究平台，集成了6大Web引擎，实现"没有AI Agent访问不了的数据源"，包括OpenCLI、Scrapling、Lightpanda、PinchTab、bb-browser、CLIBrowser等
- 5层智能降级机制（SiteAdapter → HTTP → CDP → Dynamic → Stealth → CLIBrowser）确保了网页内容提取的可靠性
- 意图感知查询扩展功能，支持9种查询意图和130+关键词模式，提高了搜索和提取的准确性
- 熔断+限流+重试机制，每引擎独立健康监控，确保了系统的稳定性

## 技术实现

### 已实现的核心服务

1. **TextChunkingService** - 文本分块服务
   - 支持基于字符、句子和段落的分块策略
   - 提供token数量估计和优化分块功能
   - 实现了智能分块算法，根据文本长度和类型自动调整

2. **WebContentExtractionPipeline** - 网页内容提取管道
   - 从URL和HTML中提取内容、标题和元数据
   - 支持特定元素和链接的提取
   - 已优化为浏览器兼容，使用内置fetch API

3. **LocalStorageService** - 本地存储服务
   - 实现Local-First数据存储机制
   - 支持分析结果和提取内容的缓存
   - 提供键值对存储和管理功能

4. **TextSummaryService** - 文本摘要服务
   - 实现提取式摘要（基于TextRank算法）
   - 支持生成式摘要（模拟实现）
   - 提供摘要长度和格式控制

5. **StructuredInformationExtractionService** - 结构化信息提取服务
   - 支持提取人物、组织、地点、日期、数值等实体
   - 实现实体之间关系的提取
   - 提供自定义实体提取功能

6. **WebContentExtractionService** - 网页内容提取服务
   - 整合网页内容提取功能
   - 提供内容清洗、结构化提取、批量提取等功能
   - 集成缓存机制

7. **JSHeavyWebProcessingService** - JavaScript-heavy网页处理服务
   - 使用playwright实现动态内容的渲染和提取
   - 支持滚动加载、等待选择器、批量处理等功能
   - 已优化为浏览器兼容，仅在Node.js环境加载playwright

8. **MultiFormatSupportService** - 多格式支持服务
   - 整合现有的文档解析器
   - 支持PDF、TXT、HTML、Markdown、Word、Excel、PowerPoint、图片等多种格式
   - 提供统一的文档解析接口

9. **MultiEngineSchedulerService** - 多引擎调度服务
   - 集成HTTP、CDP、Dynamic、Stealth、CLIBrowser等引擎
   - 实现智能引擎选择、健康监控和自动降级机制
   - 已优化为浏览器兼容，仅在Node.js环境注册高级引擎

### 技术实现要点

1. **浏览器兼容性** - 所有服务都已优化为浏览器兼容，避免使用Node.js特定模块
2. **模块化设计** - 每个功能都被封装为独立的服务，便于维护和扩展
3. **性能优化** - 实现了文本分块、缓存机制等性能优化策略
4. **错误处理** - 完善的错误处理机制，确保系统稳定性
5. **可扩展性** - 支持自定义解析器和引擎的注册
6. **Local-First原则** - 数据优先存储在本地，确保隐私和离线访问
