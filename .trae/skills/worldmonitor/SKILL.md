# World Monitor 技能

## 技能名称
World Monitor

## 技能描述
将 World Monitor 实时全球情报仪表板集成到豆包中，为用户提供 AI 驱动的新闻聚合、地缘政治监控和基础设施跟踪功能，增强用户的信息获取和决策支持能力。

## 功能特点
- **新闻聚合**：435+ 精选新闻源，覆盖 15 个类别，AI 合成简报
- **双地图引擎**：3D 地球（globe.gl）和 WebGL 平面地图（deck.gl），45 个数据层
- **跨流关联**：军事、经济、灾难和升级信号的融合分析
- **国家情报指数**：12 个信号类别的综合风险评分
- **金融雷达**：92 个股票交易所、商品、加密货币和 7 信号市场组合
- **本地 AI**：使用 Ollama 运行模型，无需 API 密钥
- **多语言支持**：21 种语言，支持母语源和 RTL 布局
- **多站点变体**：从单一代码库提供 5 个站点变体（world、tech、finance、commodity、happy）

## 安装要求
- **浏览器**：支持 Chrome、Firefox、Edge、Brave 等主流浏览器
- **本地 AI 模型**：需要安装 Ollama 或其他兼容的本地 AI 模型
- **Node.js**：需要安装 Node.js 16.0 及以上版本
- **World Monitor**：需要克隆和构建 World Monitor 项目

## 安装步骤

### 1. 安装本地 AI 模型
- **下载并安装 Ollama**：访问 https://ollama.com/download 下载适合您操作系统的版本
- **安装 Ollama**：按照安装向导完成安装
- **启动 Ollama 服务**：
  - Windows：Ollama 会自动启动并在系统托盘运行
  - macOS：Ollama 会自动启动并在菜单栏运行
  - Linux：使用命令 `ollama serve` 启动服务
- **验证 Ollama 安装**：打开终端，运行 `ollama --version` 查看版本信息

### 2. 安装 World Monitor
- **克隆 World Monitor 仓库**：`git clone https://github.com/koala73/worldmonitor.git`
- **进入项目目录**：`cd worldmonitor`
- **安装依赖**：`npm install`
  - 注意：如果遇到依赖安装失败，可以尝试使用 `npm install --legacy-peer-deps`
- **构建项目**：`npm run build:full`
  - 此过程可能需要较长时间，因为需要下载和处理大量数据

### 3. 配置 World Monitor
- **启动开发服务器**：`npm run dev`
- **打开浏览器访问**：`http://localhost:5173`
- **确保 World Monitor 能够正常运行**：
  - 检查页面是否成功加载
  - 检查新闻数据是否能够正常显示
  - 检查地图功能是否能够正常使用

### 4. 配置豆包
- **启动豆包**：进入豆包项目目录，运行 `npm run dev`
- **打开豆包**：在浏览器中访问 `http://localhost:3000`
- **启用 World Monitor 技能**：
  - 进入豆包技能库
  - 找到 World Monitor 技能
  - 点击启用按钮
- **配置 World Monitor 服务地址**：
  - 在 World Monitor 技能设置中
  - 输入 World Monitor 服务地址（默认为 `http://localhost:5173`）
  - 点击保存按钮

## 使用方法

### 访问 World Monitor
1. **打开豆包**：在浏览器中访问 `http://localhost:3000`
2. **进入技能库**：点击左侧导航栏中的「技能库」选项
3. **启动 World Monitor**：找到 World Monitor 技能，点击「启动」按钮
4. **选择站点变体**：
   - **world**：全球综合情报
   - **tech**：科技领域情报
   - **finance**：金融市场情报
   - **commodity**：商品市场情报
   - **happy**：积极正面的新闻
5. **开始使用**：进入 World Monitor 仪表板，开始浏览全球情报

### 新闻聚合功能
1. **查看新闻简报**：在 World Monitor 界面顶部查看 AI 合成的新闻简报
2. **浏览新闻类别**：
   - 点击左侧新闻类别标签（政治、经济、科技、军事等）
   - 查看对应类别的新闻列表
3. **查看详细新闻**：
   - 点击新闻标题或卡片
   - 在弹出的详细窗口中查看完整新闻内容
   - 阅读 AI 生成的新闻摘要和分析
4. **搜索新闻**：
   - 在顶部搜索栏中输入关键词
   - 按回车键或点击搜索按钮
   - 查看搜索结果

### 地图功能
1. **切换地图类型**：
   - 点击地图右上角的「3D 地球」或「2D 平面」按钮
   - 体验不同的地图视角
2. **浏览数据层**：
   - 点击地图左侧的数据层控制面板
   - 选择要显示的数据层（军事、经济、基础设施、灾难等）
   - 调整数据层的透明度和显示方式
3. **交互操作**：
   - **缩放**：使用鼠标滚轮或双指缩放
   - **平移**：按住鼠标左键拖动或双指拖动
   - **旋转**：按住鼠标右键拖动（3D 地球模式）
4. **查看标记详情**：
   - 点击地图上的标记点
   - 在弹出的信息窗口中查看详细信息
   - 点击「查看更多」链接获取完整数据

### 数据分析功能
1. **国家情报指数**：
   - 在分析面板中查看各国的情报指数
   - 了解 12 个信号类别的综合风险评分
   - 点击国家名称查看详细分析
2. **金融市场分析**：
   - 查看 92 个股票交易所的实时数据
   - 分析商品和加密货币的市场趋势
   - 查看 7 信号市场组合的表现
3. **深度 AI 分析**：
   - 点击「AI 分析」按钮
   - 输入分析请求（例如：「分析近期地缘政治风险」）
   - 等待本地 AI 模型生成分析报告
   - 查看 AI 生成的深度分析结果

### 多语言支持
1. **切换语言**：
   - 点击右上角的语言选择器
   - 从下拉菜单中选择目标语言
   - 界面会自动切换到所选语言
2. **语言支持**：
   - 支持 21 种语言，包括英语、中文、西班牙语、法语等
   - 支持 RTL（从右到左）布局的语言（如阿拉伯语）
   - 新闻和数据会根据所选语言进行翻译和显示

### 站点变体使用
1. **world**：全球综合情报，适合全面了解全球动态
2. **tech**：科技领域情报，专注于科技新闻和创新
3. **finance**：金融市场情报，聚焦于全球金融动态
4. **commodity**：商品市场情报，关注能源、金属等商品价格
5. **happy**：积极正面的新闻，提供鼓舞人心的故事

### 实用操作技巧
1. **快捷键**：
   - `Ctrl/Cmd + F`：打开搜索栏
   - `Ctrl/Cmd + R`：刷新数据
   - `Esc`：关闭弹出窗口
2. **数据导出**：
   - 点击数据面板右上角的导出按钮
   - 选择导出格式（CSV、JSON、PDF）
   - 下载数据文件
3. **收藏内容**：
   - 点击新闻或分析旁边的星标图标
   - 在「收藏」标签页中查看收藏的内容
4. **分享功能**：
   - 点击分享按钮
   - 选择分享方式（链接、社交媒体、邮件）
   - 分享感兴趣的内容

## 常见问题

### Q: 无法连接到本地 AI 模型
**A**: 请确保本地 AI 模型（如 Ollama）已经启动，并且 World Monitor 的配置正确。

### Q: 地图功能无法正常显示
**A**: 请确保浏览器支持 WebGL，并且网络连接正常。

### Q: 数据加载缓慢
**A**: World Monitor 处理大量数据，首次加载可能需要一些时间。请确保网络连接稳定。

### Q: 新闻源无法更新
**A**: 请检查网络连接，以及新闻源的可用性。

### Q: 本地 AI 分析失败
**A**: 请确保本地 AI 模型已经正确安装和配置，并且模型文件完整。

## 注意事项

### 系统要求
- **硬件要求**：
  - 处理器：至少 4 核 CPU
  - 内存：至少 8GB RAM（推荐 16GB 以上）
  - 存储：至少 50GB 可用空间
  - 显卡：支持 WebGL 2.0 的显卡（对于地图功能）
- **软件要求**：
  - 操作系统：Windows 10/11、macOS 10.15+、Linux
  - 浏览器：最新版本的 Chrome、Firefox、Edge、Brave
  - Node.js：v16.0 及以上
  - Ollama：v0.1.0 及以上

### 使用限制
- **数据使用**：
  - 请尊重数据源的使用条款和限制
  - 不要将数据用于商业用途，除非获得相应授权
  - 引用数据时请注明来源
- **API 限制**：
  - 某些功能可能需要特定的 API 密钥或权限
  - 请遵守 API 提供商的使用限制和配额
  - 避免过度请求导致 API 被封禁
- **网络限制**：
  - 数据更新频率可能受网络连接和服务器响应时间的影响
  - 某些新闻源和数据可能在特定地区无法访问
  - 建议使用稳定的网络连接以获得最佳体验

### 性能优化
- **内存管理**：
  - World Monitor 处理大量数据，需要确保设备有足够的内存
  - 定期关闭不必要的应用程序以释放内存
  - 考虑增加系统内存以提高性能
- **CPU 资源**：
  - 本地 AI 功能需要足够的计算资源
  - 运行 AI 分析时，避免同时运行其他高 CPU 占用的应用
  - 对于复杂的 AI 分析，可能需要等待较长时间
- **网络优化**：
  - 使用高速稳定的网络连接
  - 考虑使用有线网络连接以获得更稳定的性能
  - 避免在网络高峰期使用数据密集型功能

### 安全注意事项
