# Page Assist 扩展使用指南

## 基本操作

### 打开侧边栏

您可以通过以下方式打开 Page Assist 侧边栏：

1. **快捷键**：
   - 默认：Ctrl+Shift+Y
   - 可在浏览器扩展设置中自定义

2. **上下文菜单**：
   - 右键点击网页
   - 选择 "Open Page Assist"

3. **扩展图标**：
   - 点击浏览器工具栏中的 Page Assist 图标
   - 选择 "Open Sidebar"

### 打开 Web UI

您可以通过以下方式打开 Page Assist Web UI：

1. **快捷键**：
   - 默认：Ctrl+Shift+L
   - 可在浏览器扩展设置中自定义

2. **扩展图标**：
   - 点击浏览器工具栏中的 Page Assist 图标
   - 选择 "Open Web UI"

### 打开 OpenCLI 终端

您可以通过以下方式打开 OpenCLI 命令执行界面：

1. **快捷键**：
   - 默认：Ctrl+Shift+T
   - 可在浏览器扩展设置中自定义

2. **侧边栏**：
   - 打开 Page Assist 侧边栏
   - 点击工具栏中的终端图标

## 与本地 AI 模型交互

### 发送消息

1. **在侧边栏中**：
   - 在输入框中输入消息
   - 按 Enter 键或点击发送按钮
   - 等待 AI 回复

2. **在 Web UI 中**：
   - 在输入框中输入消息
   - 按 Enter 键或点击发送按钮
   - 等待 AI 回复

### 模型选择

1. **在侧边栏中**：
   - 点击模型选择器
   - 从下拉菜单中选择模型
   - 新选择的模型将用于后续对话

2. **在 Web UI 中**：
   - 点击模型选择器
   - 从下拉菜单中选择模型
   - 新选择的模型将用于后续对话

### 消息历史

1. **查看历史**：
   - 在侧边栏中，消息历史会自动显示
   - 在 Web UI 中，点击左侧的历史记录图标

2. **开始新对话**：
   - 在侧边栏中，点击 "New Chat" 按钮
   - 在 Web UI 中，点击 "New Chat" 按钮

## 与网页内容交互

### 进入与网页对话模式

1. **在侧边栏中**：
   - 点击 "与网页对话" 按钮
   - 系统会自动提取当前网页内容
   - 进入与网页内容相关的对话模式

2. **退出与网页对话模式**：
   - 再次点击 "与网页对话" 按钮
   - 系统会退出该模式并返回普通对话模式

### 针对网页内容提问

1. **在与网页对话模式下**：
   - 在输入框中输入关于网页内容的问题
   - 例如："这个网页主要讲了什么？"
   - 按 Enter 键或点击发送按钮
   - AI 会基于网页内容给出回答

2. **示例问题**：
   - "总结这个网页的主要内容"
   - "这个网页有哪些重要信息？"
   - "解释这个网页中的概念"
   - "这个网页的结构是什么？"

## OpenCLI 命令执行

### 执行基本命令

1. **打开 OpenCLI 终端**：
   - 点击工具栏中的终端图标
   - 或使用快捷键 Ctrl+Shift+T

2. **输入命令**：
   - 在命令输入框中输入 OpenCLI 命令
   - 例如：`google/search --query "OpenCLI"`

3. **执行命令**：
   - 点击执行按钮或按 Enter 键
   - 等待命令执行完成
   - 查看命令执行结果

### 命令语法

OpenCLI 命令的基本语法：
```
<command> [options] [arguments]
```

- **command**：命令名称，如 `google/search`、`github/repo` 等
- **options**：命令选项，以 `--` 开头，如 `--query`、`--limit` 等
- **arguments**：命令参数，根据命令的不同而不同

### 常用命令示例

1. **搜索命令**：
   - Google 搜索：`google/search --query "OpenCLI"`
   - GitHub 搜索：`github/search --query "opencli" --type repo`
   - 百度搜索：`baidu/search --query "OpenCLI"`

2. **社交媒体命令**：
   - 微博热搜：`weibo/hot`
   - 知乎热榜：`zhihu/hot`
   - B 站热门：`bilibili/ranking`

3. **工具命令**：
   - 天气查询：`weather --city "北京"`
   - 翻译：`translate --text "Hello" --from en --to zh`
   - 计算器：`calc --expression "1+2*3"`

## 命令历史记录

### 查看历史命令

1. **打开历史记录**：
   - 在 OpenCLI 终端中，点击历史记录按钮
   - 或使用快捷键 Ctrl+H

2. **浏览历史命令**：
   - 滚动查看历史命令列表
   - 点击历史命令重新执行

3. **搜索历史命令**：
   - 在搜索框中输入关键词
   - 过滤显示匹配的历史命令

### 管理历史记录

1. **清除历史记录**：
   - 在历史记录界面，点击 "Clear History" 按钮
   - 确认清除操作

2. **设置历史记录数量**：
   - 在扩展设置中，找到 "OpenCLI" 配置
   - 设置 "命令历史记录" 的最大数量

## 命令录制

### 开始录制

1. **打开录制功能**：
   - 在 OpenCLI 终端中，点击录制按钮
   - 或使用快捷键 Ctrl+R

2. **执行操作**：
   - 在网页上执行需要录制的操作
   - 如点击、输入、导航等

3. **停止录制**：
   - 点击停止按钮
   - 或使用快捷键 Ctrl+R

4. **查看生成的命令**：
   - 录制完成后，会显示生成的 OpenCLI 命令
   - 可以编辑和保存命令

### 录制注意事项

1. **权限要求**：
   - 录制功能需要浏览器的相关权限
   - 确保权限设置正确

2. **操作类型**：
   - 支持点击、输入、导航、滚动等操作
   - 某些复杂操作可能无法录制

3. **命令生成**：
   - 录制的操作会转换为 OpenCLI 命令
   - 可能需要手动调整生成的命令

## 批量执行和命令队列

### 创建命令队列

1. **打开命令队列**：
   - 在 OpenCLI 终端中，点击队列按钮
   - 或使用快捷键 Ctrl+Q

2. **添加命令**：
   - 在队列界面中，输入命令并点击 "Add" 按钮
   - 可以添加多个命令

3. **调整命令顺序**：
   - 拖动命令调整执行顺序
   - 点击命令删除不需要的命令

### 执行命令队列

1. **开始执行**：
   - 点击 "Start" 按钮开始执行队列
   - 命令会按顺序执行

2. **暂停执行**：
   - 点击 "Pause" 按钮暂停执行
   - 可以在任何时候暂停

3. **继续执行**：
   - 点击 "Resume" 按钮继续执行
   - 从暂停的位置继续

4. **取消执行**：
   - 点击 "Cancel" 按钮取消执行
   - 队列会被清空

## 配置选项

### AI 服务配置

1. **Ollama**：
   - 地址：默认为 http://localhost:11434
   - 模型：可以选择本地安装的模型

2. **OpenAI API**（可选）：
   - API 密钥：输入您的 OpenAI API 密钥
   - 模型：选择 OpenAI 模型

3. **自定义 AI 服务**（可选）：
   - 服务地址：输入自定义 AI 服务的地址
   - 认证信息：根据需要配置

### OpenCLI 配置

1. **OpenCLI 地址**：
   - 默认为 http://localhost:8080
   - 确保 OpenCLI 守护进程已启动

2. **命令执行超时**：
   - 默认：30 秒
   - 根据需要调整

3. **命令历史记录**：
   - 默认：1000 条
   - 根据需要调整

### 扩展设置

1. **外观**：
   - 主题：浅色/深色
   - 字体大小：调整字体大小

2. **行为**：
   - 自动启动：是否在浏览器启动时自动启动
   - 通知：是否启用通知

3. **快捷键**：
   - 打开侧边栏：自定义快捷键
   - 打开 Web UI：自定义快捷键
   - 打开 OpenCLI 终端：自定义快捷键

## 最佳实践

### 与网页内容交互

1. **提取完整内容**：
   - 确保网页完全加载后再提取内容
   - 对于长网页，可能需要等待一段时间

2. **精确提问**：
   - 针对网页的具体部分提问
   - 使用明确的问题表述

3. **利用上下文**：
   - 连续提问时，AI 会记住之前的对话内容
   - 可以基于之前的回答继续提问

### OpenCLI 命令执行

1. **命令选择**：
   - 根据需要选择合适的命令
   - 参考命令帮助信息

2. **参数设置**：
   - 正确设置命令参数
   - 注意参数的格式和取值范围

3. **错误处理**：
   - 查看命令执行的错误信息
   - 根据错误信息调整命令

### 命令录制和队列

1. **录制复杂操作**：
   - 对于复杂的网页操作，使用录制功能
   - 可以多次录制并组合命令

2. **批量处理**：
   - 对于需要重复执行的操作，使用命令队列
   - 可以设置命令执行顺序和条件

3. **自动化工作流**：
   - 组合多个命令创建自动化工作流
   - 提高工作效率

### 模型选择

1. **根据任务选择模型**：
   - 通用对话：选择通用模型
   - 代码相关：选择代码模型
   - 多模态：选择支持图像的模型

2. **考虑性能**：
   - 大型模型：更准确但响应较慢
   - 小型模型：响应更快但可能不够准确

## 故障排除

### AI 无响应

1. **检查连接**：
   - 确认本地 AI 模型是否正在运行
   - 检查网络连接
   - 尝试重新启动扩展

2. **检查配置**：
   - 确认 AI 服务地址配置正确
   - 检查 API 密钥（如果使用 OpenAI API）

### 网页内容提取失败

1. **刷新网页**：
   - 刷新网页后重新尝试
   - 等待网页完全加载

2. **检查权限**：
   - 确认浏览器权限设置正确
   - 尝试在不同的网页上测试

### OpenCLI 命令执行失败

1. **检查守护进程**：
   - 确认 OpenCLI 守护进程正在运行
   - 检查 OpenCLI 日志是否有错误信息

2. **检查命令格式**：
   - 确认命令格式正确
   - 参考命令帮助信息

3. **检查网络连接**：
   - 确认网络连接正常
   - 检查防火墙设置

### 命令录制功能不工作

1. **检查权限**：
   - 确认浏览器权限设置正确
   - 特别是对网页操作的权限

2. **检查 OpenCLI**：
   - 确认 OpenCLI 守护进程正在运行
   - 检查 OpenCLI 日志是否有错误信息
